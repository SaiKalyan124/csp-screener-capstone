CSP Screener Blueprint

Three diagrams, one per build milestone, showing how the cash-secured put screener's components connect and what gets added at each stage — from a conversational MVP, to an app that ranks candidates, to an always-on platform with memory. Milestone 1 is Milestone 2 minus the deterministic Score & Rank engine; Milestone 3 is a separate application that adds persistent memory and user profiles, reusing the Score & Rank engine and the tool-calling pattern rather than Milestone 2's codebase.

Chat and reasoning run as a LangGraph agent that invokes the OpenAI API and issues typed tool calls — validated with Pydantic BaseModel schemas. The agent decides what to do and explains the result, but it never does the numbers itself: scoring and ranking run in a deterministic Score & Rank engine (our own code plus finance APIs), not the LLM. In Milestone 2 the agent reasons over data pulled live from tools — the Yahoo Finance MCP for quotes, fundamentals and options, the Alpaca / Robinhood MCP for live pricing, Tavily web search as a fallback — and calls the Score & Rank engine for any ranked comparison. Gold, accent-colored arrows in the diagrams below mark those tool calls specifically.

Conversational MVP

Milestone 2

Interactive Web App

Modality: standalone web app (e.g. Streamlit) · any ticker, not just the static list · deterministic Score & Rank · chat handled by a LangGraph agent · session-only, no saved state

any ticker budget / risk / timeline deterministic Score & Rank Yahoo Finance MCP Tavily fallback
Milestone 3 is scoped as a separate application from Milestone 2 — a new frontend and a new backend with real infrastructure behind it, not an extension of the Streamlit prototype. It reuses the deterministic Score & Rank engine and the LangGraph/OpenAI/MCP tool-calling pattern, and adds what Milestone 2 deliberately left out: persistent memory and user profiles.

Milestone 3

Automated Platform

Modality: separate app, own backend · multi-turn LangGraph agent over OpenAI · scheduled reports · background ticker refresh · persistent memory & user profiles
